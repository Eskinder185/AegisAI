# Visual & functional QA report — premium UX pass (2026-11-05)

## Method
Playwright (Chromium) against the live stack: Vite dev server, FastAPI, and the standalone worker, with axe-core
(WCAG 2.0/2.1/2.2 A+AA tags, serious/critical only). Screenshots are regenerated by
`npx playwright test specs/screenshots.spec.ts` into [screenshots/](screenshots/) (desktop light, desktop dark, phone light).
Screenshots were **reviewed by me for: overview (tablet), case page, home, attack-path (desktop dark + phone), replay (desktop light), phone overview**.
The remaining images in the folder were captured but not individually reviewed.

## Results
| Check | Result |
|---|---|
| Playwright E2E | 51 passed, run twice back to back (includes 3 screenshot-capture tests) |
| axe on all public pages, all app pages in light + dark, palette, graph (graph + list), replay, agents | no serious/critical violations |
| Horizontal overflow at 390 px and 820 px | none on tested pages |
| Backend pytest | 86 passed |
| Frontend vitest | 12 passed |

## Issues found by this pass and fixed
| Issue | How found | Fix |
|---|---|---|
| Opening the command palette crashed the app (effect returned a non-function) | E2E + console probe | block-bodied effects |
| Escape did not close the palette if pressed before autofocus | E2E | document-level Escape while open |
| Phone top bar wrapped to 3 rows | screenshot | secondary controls hidden below 640 px; actions reachable via palette |
| Attack-path graph unreadable on a phone | screenshot | phones default to the accessible list layout |
| **Read-after-write race**: a fresh record could 404 right after creation (1/300 on keep-alive) | E2E flake → probe script | DB sessions now commit before the response is sent (`scope="function"`); 0/900 afterwards (`scripts/probe_read_after_write.py`) |
| **Audit hash-chain forks** when API and worker wrote simultaneously | E2E failure → fork analysis | audit writers serialised with a lock row; multi-threaded regression test fails without the fix |

## Not verified / limitations
- No screen-reader (NVDA/VoiceOver) testing; only axe and role/name queries. Keyboard operation was tested for palette, graph nodes, replay slider and chords.
- Phone screenshots were taken at 390 px only; tablet only for overflow. No Safari/Firefox runs.
- Graph pan by dragging and wheel-zoom are implemented but only button/keyboard zoom is covered by tests.
- Contrast was checked by axe in the tested states only (default, not every hover/disabled state).
